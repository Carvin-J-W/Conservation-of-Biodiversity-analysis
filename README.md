# Biodiversity Data Analysis

### What is this repository about?

In this repository I undergo a basic data analysis. The two CSV files that contain our data belongs to USA National Park Services. One CSV contains species data pertaining to the species, and the other CSV contains observation data which essentially counts how many times a species was observed in a particular park. 

### Goals:

The central goal of this analysis is conservation. How many species are endangered? What species are endangered? What is the spread of conservation status? Where are the animals endangered the most?

### Extra Notes:

Mostly at the bottom of the jupyter notebook I visualize the data with some graphs. There is visible endangerment of species throughout the all parks.
